Pengertian Decision Tree

Decision Tree adalah salah satu algoritma dalam Artificial Intelligence (AI) dan Machine Learning yang digunakan untuk mengambil keputusan berdasarkan serangkaian aturan berbentuk pohon.

Struktur Decision Tree terdiri dari:

  • Root Node (Akar): Titik awal pengambilan keputusan
  • Decision Node (Node Keputusan): Node yang berisi pertanyaan atau kondisi tertentu
  • Branch Node (Node Cabang): Titik di mana pengambilan keputusan dilakukan berdasarkan kondisi
  • Leaf Node (Node Daun): Titik akhir yang menghasilkan keputusan akhir

Penerapan Decision Tree di Dunia Nyata

  • Diagnosis penyakit
  • Deteksi fraud perbankan
  • Persetujuan kredit
  • Prediksi cuaca
2

Logika Decision Tree (Representasi Pohon)

Logika: Jika cuaca cerah dan kelembapan rendah, maka boleh main tennis. Jika kelembapan tinggi meskipun cerah, sebaiknya tidak main. Jika cuaca tidak cerah, main tennis tanpa ragu.
